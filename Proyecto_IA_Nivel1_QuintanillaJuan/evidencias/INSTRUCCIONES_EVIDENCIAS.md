# Evidencias de Pruebas — AgendaBot

Esta carpeta contiene las capturas de pantalla de las 60 pruebas requeridas (Artículo 13).

## Organización sugerida

```
evidencias/
├── navegacion/       N-01.png ... N-30.png
├── agendamientos/    A-01.png ... A-10.png
├── errores/          E-01.png ... E-10.png
├── recordatorios/    R-01.png ... R-10.png
└── permisos/         P-01.png ... P-10.png
```

## Qué capturar en cada prueba

Para cada prueba tomar dos capturas:
1. **Chat de Telegram** — mostrando la entrada del usuario y la respuesta del bot
2. **Google Sheets** — mostrando el registro en LOGS (y en la hoja correspondiente si hubo guardado)

## Nomenclatura

`N-01_start.png`, `A-01_cita_completa.png`, `E-03_fecha_invalida.png`, etc.
